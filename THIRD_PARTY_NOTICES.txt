Bundled programs
----------------

ffmpeg - GNU LGPL (v2.1 or later on Windows, v3 or later on Linux)
    A small ffmpeg built for this app from the unmodified FFmpeg 9.0.2 source
    (https://ffmpeg.org/, tag n9.0.2), with only what the app uses: it decodes
    the audio YouTube serves and encodes Opus in Ogg. It is not a GPL build:
    no GPL or non-free components are included. It runs as a separate program
    (ffmpeg.exe, or ffmpeg on Linux) that the bot starts, so it can be replaced
    with any other ffmpeg that has libopus. Licence text: FFMPEG-LICENSE.txt in
    the bin folder next to it. The complete, exact recipe (source URLs and
    SHA-256 checksums, configure options, build script) is in this project:
    packaging/tools.lock.json and packaging/ffmpeg/build.sh. https://ffmpeg.org/legal.html
    Built in: libopus 1.6.1 (BSD-3-Clause, https://opus-codec.org/); on Windows
    TLS comes from the operating system (Schannel); on Linux OpenSSL
    (Apache-2.0, https://www.openssl.org/) is linked in statically, which is why
    that build is LGPL v3.

Downloaded at runtime, not shipped
----------------------------------

yt-dlp JS challenge solver scripts - Unlicense
    https://github.com/yt-dlp/ejs
    These are NOT part of the installer. yt-dlp downloads the scripts that match
    its own version over HTTPS the first time it needs them and keeps them in
    the PyxeeRadio data folder (%APPDATA%\TwitchRadio\data\yt-dlp-cache). They
    run inside the bundled QuickJS runtime.

yt-dlp updates - Unlicense
    If you press "Update" in Settings > App, a newer yt-dlp release is downloaded
    from https://github.com/yt-dlp/yt-dlp (checksum verified) into
    %APPDATA%\TwitchRadio\yt-dlp.
